Dernière mise à jour indiquée dans cette source : 1er octobre pour Dot Navigator, 25 septembre pour Auto Expander et 7 octobre pour Workflow Boards, en 2026. La date publique désigne la consultation, pas un calcul en temps réel.

Les téléchargements peuvent inclure les mises à jour ; ils ne mesurent ni les utilisateurs uniques ou actifs, ni un résultat commercial. Les stars indiquent un intérêt sur GitHub. Aucune somme globale ni preuve de qualité de conseil n’en est déduite.

Le README de Dot Navigator et celui d’Auto Expander contiennent encore des instructions antérieures à leur inscription au registre. La présence effective dans le registre prime pour les liens de fiche Obsidian. Les pages `obsidian.md/plugins?id=…` répondent 403 aux requêtes automatisées dans cet environnement ; leur contenu n’a donc pas pu être inspecté. Les dépôts et les entrées du registre ont été vérifiés directement.

Rename Wizard est écarté : son README indique qu’il est abandonné au profit de Dot Navigator. Les forks et projets sans documentation suffisante ne sont pas présentés comme des réalisations originales détaillées.
